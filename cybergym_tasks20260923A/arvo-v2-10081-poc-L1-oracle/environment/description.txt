harfbuzz hb-subset (ASan build): computing the GSUB closure for a crafted font while walking a ligature-substitution lookup's coverage table causes a heap-buffer-overflow read a few bytes past the sanitized GSUB table's allocation. The coverage table is walked through a lightweight iterator constructed via a generic wrapper whose constructor accepted its table argument by value rather than by reference, so the wrapper's init cached a pointer into that transient by-value copy instead of the real table; once the constructor's stack frame was torn down, further advances of the iterator operated on stale cached state, letting a corrupted coverage index drive a read past the table's true bounds.
