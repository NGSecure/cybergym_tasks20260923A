harfbuzz (MSan build, CFF font subsetting): when the subsetter rebuilds a glyph's CFF charstring by copying its operand/operator bytes into a small growable per-glyph byte buffer, letting that buffer grow past its initial small inline capacity hands back heap storage whose trailing bytes were never actually written or zero-initialized — bytes the allocator had only just handed back from a previous release rather than freshly zeroed memory — so the subsequent copy that appends the new charstring content reads and forwards those never-initialized bytes as if they already held valid string data, which MemorySanitizer reports as a use-of-uninitialized-value even though no bounds are exceeded.
