Skia's text-blob deserialization fuzz target (MSan build): a use-of-uninitialized-value is reported while replaying an untrusted serialized SkTextBlob whose embedded paint references a radial-gradient shader built over an unusual, non-default color space. When Skia constructs the internal helper object that decides how to convert colors between a source and a destination color space for a draw, it independently computes two things that are supposed to stay in lockstep: a boolean flag saying whether a gamut (RGB-primaries) conversion matrix will be needed for this pair of color spaces, and the actual 3x3 matrix coefficients that later per-pixel color math will read when that flag is set. The flag is derived from a coarse comparison of the two color spaces' XYZ-referenced profiles, while the matrix coefficients are only populated inside a narrower branch that additionally requires both profiles to be non-null and requires the combined transform they produce to pass an extra structural sanity check on its unused border entries. For a source/destination color-space pairing that is unusual enough to trip the flag's coarse comparison but fails that stricter follow-up check, the helper ends up with the flag set while its matrix-coefficient storage — plain floating-point fields inside a short-lived, stack-allocated object — is left completely unwritten. Immediately afterward, the routine that actually transforms a pixel's color values trusts the flag alone: seeing it set, it unconditionally multiplies the pixel's components against those never-initialized coefficients and passes the result into further per-channel transfer-function evaluation, which is where the sanitizer's read of uninitialized memory is ultimately observed. In short, the root cause is a mismatch between the condition used to decide "a gamut transform is required" and the stricter condition used to decide "the gamut-transform matrix has actually been filled in," letting the two states diverge for certain crafted color-space inputs and leaving downstream color math to consume garbage stack memory.
