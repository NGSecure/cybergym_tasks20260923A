Wireshark (UBSan build): dissecting a crafted IEEE 802.11 HE Compressed Beamforming/CQI action frame, the subcarrier-index walker derives a start/end index from the frame's bandwidth and grouping fields and uses it to index one of several fixed-size per-bandwidth lookup tables without checking it against that table's actual length, so an attacker-controlled index past the table's bound causes an out-of-bounds array read.
