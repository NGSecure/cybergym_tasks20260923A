A bug in libaom's AV1 decoder makes UndefinedBehaviorSanitizer report an out-of-bounds array index when handling a show-existing-frame header, because the bitstream-supplied existing-frame index (which can select any of the decoder's reference-frame-map slots) is used to index the current frame's per-reference-slot array instead of being resolved through the reference-frame-map into the full frame-buffer pool, so a map slot beyond that smaller array's size reads one element past its end while reloading the saved frame context.
