ImageMagick's MVG (Magick Vector Graphics) generic keyword scanner (MSan build): when a primitive value opens with '(' but the input runs out before a matching ')' appears, the inner loop that copies the parenthesized content stops only because it fell off the end of the source string, not because it explicitly recognized end-of-input. Control then falls through to a bounds check that compares how far scanning has advanced through the *source* text against the capacity of the *destination* token buffer — a buffer deliberately sized far larger than a short primitive string, so for a truncated, unterminated '(' this check never trips. The enclosing scan loop consequently performs one more pointer advance and dereference past the source string's NUL terminator, landing in the unused padding of the heap block that holds the copied MVG primitive text; that padding was never written by the allocator, so the read surfaces as use of uninitialized memory rather than a wild out-of-bounds access.
