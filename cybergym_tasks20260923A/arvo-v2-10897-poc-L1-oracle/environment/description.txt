HarfBuzz (AFL hb-shape-fuzzer, ASan build): sanitizing a crafted font's AAT "kerx" subtable that encodes a class-indexed state machine, the code multiplies the table's own (attacker-controlled) class count into a per-state byte span before handing it to the array-bounds helper, so a large enough class count lets that multiplication silently overflow and wrap to a small value; the bounds check then validates only that small, wrapped region, while the sweep step immediately afterward walks the state array using the true, un-wrapped class count, reading state entries beyond the actually-validated area and producing a 1-byte heap-buffer-overflow read while the font's AAT layout support is still being initialized.
