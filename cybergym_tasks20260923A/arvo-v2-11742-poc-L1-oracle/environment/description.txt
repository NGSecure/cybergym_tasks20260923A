GraphicsMagick's TIFF coder trips a MemorySanitizer use-of-uninitialized-value warning while decompressing a PixarLog-compressed tile in a pyramid TIFF (PTIF) image. Root cause: libtiff's PixarLog decoder feeds a corrupted/truncated compressed tile into the same zlib decompression engine, and the engine's stream-resync error-recovery path ends up reading window bytes that were never initialized for that tile — the tile-based counterpart of the strip-based ZIP-decode case.
