MuPDF (MSan build): decoding a JBIG2-compressed image stream via its bundled bitmap decoder's generic-refinement region path reads an arithmetic-coder context byte that MSan reports as never fully initialized, triggering a use-of-uninitialized-value warning inside the arithmetic decoder's core decode routine. The crash is resolved by a broad update to the bundled bitmap decoder library that, among other changes, closes a return path in that same decode routine which had been skipping initialization of one of its output values -- the exact origin of the uninitialized context byte within the decoder's internal state was not independently isolated beyond that.
