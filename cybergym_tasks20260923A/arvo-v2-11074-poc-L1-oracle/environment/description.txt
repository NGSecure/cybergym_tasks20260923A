In HarfBuzz (AFL+ASan hb-shape fuzz target), sanitizing an AAT `kerx` state-table's trimmed per-glyph value-lookup subtable reads a heap-buffer-overflow: the subtable's minimum-size check under-counts its own fixed header by one 16-bit field, so a font with a truncated/malformed lookup header passes the size check yet the sanitizer still reads that missing field (used to size the value array) from just past the end of the allocated font-table buffer.
