GraphicsMagick (MSan build): while decoding a DICOM (medical-imaging) file, the routine that classifies the image's declared photometric-interpretation attribute copies the attribute's raw bytes into a fixed-size stack buffer without first zeroing it, then repeatedly compares that whole buffer against several known interpretation-name constants using fixed-length string comparisons. Root cause: when the attribute's actual data length is shorter than the constant being compared against, the comparison reads past the bytes that were actually copied into stack memory that was never initialized, triggering a use-of-uninitialized-value warning.
