In radare2's minidump (MDMP) crash-dump loader (ASan build), a memory-info-list stream's declared entry count is never checked against how much stream data is actually present, so the parser builds a list of per-region metadata entries whose later ones point past the end of the loaded file buffer; when the section builder subsequently looks up a mapped page's protection flags by walking that list, it dereferences one of those out-of-bounds entries, producing an 8-byte heap-buffer-overflow read.
