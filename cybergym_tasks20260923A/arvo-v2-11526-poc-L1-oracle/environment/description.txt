harfbuzz (ASan build, hb-shape-fuzzer target): shaping a font whose legacy "kern" table is encoded in its older, plain-OpenType subtable variant (16-bit subtable-length field) triggers a heap-buffer-overflow read while the table sanitizer walks the chain of subtables — for the subtable sitting at the very end of the table's allocated buffer, the code computes that subtable's byte size (which requires reading its own length field) before ever confirming the subtable's header bytes are actually within the buffer, so that read walks past the allocation.
