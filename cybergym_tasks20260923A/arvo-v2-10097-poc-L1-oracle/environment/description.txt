In HarfBuzz (MSan), computing which glyphs a font-subsetting closure pass must retain walks a GSUB single-substitution lookup's coverage table through a local iterator built at the top of that loop; because the iterator's constructor is generic enough to bind by value instead of by reference in some builds, that local ends up holding leftover, not-fully-initialized state, and it is that same uninitialized memory that a glyph-set lookup a few lines later reads, tripping the use-of-uninitialized-value check.
