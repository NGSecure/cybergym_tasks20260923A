A bug in AV1's (libaom, ASan build) AVX2-optimized 64-wide directional high-bit-depth intra-prediction routine: while blending predicted pixels for angles that push a row's source index at or beyond the block's last valid neighboring-pixel column, the per-16-pixel-chunk boundary check only treated the exact edge index as "out of range," so every other offset within that final chunk still fell through to the normal interpolation path, which unconditionally loads a 16-wide window of neighboring-pixel data starting from that index — reading past the end of the small fixed-size stack buffer holding the reconstructed row of neighboring pixels.
