In radare2's minidump (MDMP) crash-dump loader (ASan build), when the section builder resolves a loaded module's name it only checks that the module-name record's file offset lies within the buffer, not the record's own declared UTF-16 character length, so a crafted overlong length value drives the string-conversion routine one byte past the end of the heap-allocated file buffer, producing a heap-buffer-overflow read.
