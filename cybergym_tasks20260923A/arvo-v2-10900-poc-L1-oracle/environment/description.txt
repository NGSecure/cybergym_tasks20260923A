Shaping text with an AAT `kerx` format-6 kerning subtable that uses 32-bit (long) kerning values triggers an out-of-bounds read while looking up a glyph pair's kerning value. The bounds check guarding the computed array-entry pointer uses an inverted comparison, so it rejects offsets that are actually in-bounds and lets through offsets whose entry lies beyond the subtable's declared length, so the subsequent big-endian integer read runs past the mapped table data.
