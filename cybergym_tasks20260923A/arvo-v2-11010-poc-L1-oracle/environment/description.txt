In HarfBuzz (AFL+ASan hb-shape fuzz target), shaping text with a crafted AAT 'morx' contextual-glyph-substitution subtable causes a global-buffer-overflow read. Root cause: the state machine's per-transition substitution-lookup table is reached through a generic offset-list whose element type declares a minimum validated size covering only its 2-byte format tag, even though a format-0 lookup's real size scales with the font's glyph count; an offset with only that tiny minimum of bytes free inside the table still passes sanitize-time bounds checking, so when a later transition actually indexes the lookup by glyph id, the read walks past the end of the allocated morx table.
